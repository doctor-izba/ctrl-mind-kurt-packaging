# CTRL+MIND — Ысталған / Копчёный

AI Design Hackathon 2026 packaging concept for smoked kurt, 60 g, «Гормолзавод Көкшетау».

**Interactive public demo:** https://kokshetau-kurt-demo.pages.dev/

Казахский текст первым, русский вторым. В демо используются только открытые тест-коды KURT-DEMO-01 … KURT-DEMO-08. Каждый новый код даёт 10 баллов; 40 баллов можно обменять на демонстрационную заявку. Состояние хранится только в браузере.

The public app is a synthetic simulation: no real personal data, backend, CRM, SMS or real prizes. The private local application, databases and administrator credentials are excluded from this repository.

## Submission
